# 自动化任务契约

- 用户目标与允许范围：
- 任务类型：仅运行 / 开发 / 只读调查 / 复现 / 修复 / 验收
- 资产类型：普通应用 / 指令集 / 独立网页或桌面操作
- 目标 app_id / flow_id；故障版本与编辑基线：
- 业务页面、窗口、账号/租户及记录身份：
- 输入：字段、类型、来源、正式默认值、测试值及敏感性：
- 输出及业务成功判据：
- 真实入口、对象来源和必要前置：
- 允许副作用、重复安全及停止条件：
- 验证范围与证据：正常路径、受影响边界、未知结果：
- 变更备份、临时条件、恢复和资源所有权：
- 未验证项与交付范围：

普通应用由正常主流程进入运行模块，不新增正式测试入口；指令集测试辅助不公开。临时复现辅助按维护规则恢复。项目已有结构和对外契约优先，不为填模板创建空流程或分组。
