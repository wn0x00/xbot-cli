# 变更前备份与可恢复差异

修改前保存受影响范围的真实原文/结构与身份：CodeFlow 源码、VisualFlow 块和字段、In/Out、需要改动的配置。只留 hash 或 metadata snapshot 不能恢复内容。

按风险选最轻的可靠办法：小范围精确替换可留原文、前后 diff 和回读；跨文件/接线/注册修改保留完整相关文件及相互关系。备份放工程外受控目录，记录 app_id、版本、时间、来源和恢复通道。不可恢复且无法证明修改范围时先补基线，不猜原值。

Git 适合多文件维护、需要审阅的候选或已有团队要求。可在工程外保存 CLI 读取的原文/块/参数，再使用外部 Git 记录；不在运行中应用目录初始化仓库，不自动提交或推送。用户要求 Git 基线时遵从其规则；普通小修不因没有 Git 提交而阻塞。

实际恢复仍通过受支持的客户端操作；专用指令元数据按其关闭设计器流程。恢复前回读最新状态，只撤本任务已应用差异，不用旧文件覆盖正式修复或并发编辑。运行中/结果未知先查终态，不热改或自动回滚。恢复后回读并检查，失败明确报告残留。

外部备份可能含业务数据，按项目存储规则保护；不收集无关凭据、venv 或整个用户目录。
