# 网页动作风险边界

当网页流程包含提交、删除、发送、支付、发布、账户修改或其他外部副作用时读取本文。

## 动作分级

### 只读

可以自动执行：

- 打开页面、附着活动页、刷新、后退和前进
- 获取快照、标题、URL、可见文本和表格内容
- 只读 `web eval`
- 读取流程、参数、变量、日志和诊断

### 可逆交互

通常可以在用户已授权的任务范围内执行，但每一步仍需基于最新快照：

- 填写搜索条件
- 筛选、翻页、悬停
- 展开菜单、切换选项
- 在测试环境中填写表单

### 不可逆或高影响

执行前必须说明具体动作、目标和影响，并获得用户授权：

- 提交真实表单
- 删除、覆盖或批量修改数据
- 发送消息、邮件或通知
- 下单、付款、提现
- 发布影刀应用或回收应用
- 修改账户、权限或安全设置

`--dry-run` 不会预演网页副作用；它只校验本地参数。普通 `web click` 也不自动判断按钮是否会提交，因此业务风险必须由 Agent 根据页面和任务契约判断。

## 确认点

在不可逆动作前报告：

```text
目标页面:
目标元素:
将执行的动作:
可能影响:
使用的测试或生产数据:
```

用户明确授权只覆盖已说明的动作和范围。授权发布不等于授权删除、付款或发送消息。

## 失败后的边界

如果高影响动作超时、连接中断或后续快照失败：

1. 停止继续点击或提交。
2. 查询页面、任务状态、日志或业务结果。
3. 报告动作是否已确认、未确认或结果未知。
4. 只有确认未发生且用户仍授权时，才考虑重新执行。

不要把后端返回的“selector 已保存”或进程退出成功当成业务动作成功。
