# 代码与执行

本页的指令入口及测试函数约定面向指令集。普通应用使用[应用开发差异](application-development.md)，不设置测试入口或测试函数，不将下面的指令测试模板要求套到应用上。

## 层次与入口

保持已有项目结构。通常将薄指令入口、可复用业务实现、模型/契约和测试分离；只有真实复用时才抽象，避免为每个动作增加没有职责的转发层。

CodeFlow 唯一入口为 `main(args)`。仅在 `args is None` 时初始化，不用 `args or {}` 替换调用者传入的空容器。所有 Out 先在平台声明，再写回同一个 args；Python return 不能替代 Flow Out。不在 import 时执行业务或自动运行测试。

按当前应用模板导入 `xbot`、日志/等待接口及 `package`/全局变量，使用相对模块导入。Python 语法和依赖应符合应用引擎版本，不按开发机全局解释器推断。

业务函数：校验 -> 解析并确认身份 -> 执行动作 -> 验证结果 -> 返回稳定结构。函数文档说明入参、输出、副作用和必要限制。运行时校验使用明确异常，不只依赖可被优化掉的 assert。

测试函数调用同一业务函数，不维护第二套动作。测试真实写动作前必须有相应授权和明确输入；主入口不能先测试一次再正式执行一次。离线单元测试可以 mock，但须与真实验收命名、报告分开。

## 参数读取与默认值

测试所用的具体参数值仅在 `test_*` 测试函数内部填写，不放在模块级变量或正式入口中，也不在业务函数默认形参中复制一套流程默认值。

`main(args)` 直接读取参数，例如 `account_name = args.get("account_name")`，不传第二个默认值参数。禁止用 `args.get("account_name", "测试账户")`、`args.get("account_name") or "测试账户"`、`args.setdefault(...)` 或缺值判断后赋样例值等方式兜底；即使空串、空列表、零、`False` 或 `None` 也不能擅自替换。

正式运行所需默认值直接在流程 In 参数中配置，并保持原型默认值与流程声明一致，由平台按参数契约提供。`main` 获取不到参数时无需自行补默认值，按原值传给业务函数；必填、类型或范围不合法时由业务校验明确报错，不静默补成测试值。

保留 `if args is None: args = {}` 属于入口容器处理，不是业务参数默认值；所有 Out 仍写回同一个 `args`。

## 错误、批处理和重试

先验证整批参数、对象及文件，减少执行一半才发现基础入参错误。执行时逐项记录目标、阶段、结果及已确认项。发生错误时区分：

- 未执行：参数、身份或前置状态不满足。
- 已确认成功：有业务证据支持动作已生效。
- 已确认失败：目标状态或业务返回明确拒绝。
- 结果未知：动作可能已生效，但后续观测异常或超时。

日志错误类型和阶段，保留原始异常链；不能用空 except、吞错返回成功或泛化为“网络异常”。敏感内容和完整凭据不写日志。

只读查询可按已知短暂错误有限重试。写操作超时不默认重试；先用稳定身份/回执对账。局部完成批次不能整体自动重放；补偿也需要明确业务语义和权限，不能随意删除用户数据。

## 读取与完整性

分页需要明确终止条件、稳定排序和跨页身份，处理并发新增、相同时间戳、重复键及多分片。声明全部读取时不能用“很大的 limit”替代完整读取；无法读取某分片或权限范围时，不把部分结果标为完整。

优先现有公开 API。必须适配依赖内部读取接口时，将其隔离成小型版本适配函数，检查能力、参数化查询并增加真实回归；不修改上游数据库，不吞掉查询错误。对 HTML/XML/JSON/结构化数据使用解析器。

## 界面自动化

Web DOM 和 Windows 控件分别定位。业务窗口应核对进程、窗口及账户；影刀应用 ID 只验证开发上下文。

限制树遍历的区域、深度、节点数和时间，不为找一个控件遍历整个桌面或巨型列表。优先父区域内语义定位，虚拟列表按明确滚动策略逐页检查，遇到身份歧义停止。注意时间预算不能打断卡住的 provider 调用，需要时用独立 worker 超时保护。

点击前重新核对目标、前台和遮挡。使用控件中心或安全内区，避免边缘；坐标从当前控件或截图推导，不使用旧屏幕绝对坐标。不得为清理遮挡自动关闭不相关窗口。弹窗确认、最终提交与动作后对账分别实现。

窗口句柄、运行时 UIA ID、列表索引与截图 ref 不是长期业务身份。列表重排后重新验证绑定，不按旧索引盲点。动画缩略图不适合作为唯一稳定身份。

## 依赖与资源

第三方依赖安装到应用虚拟环境并持久化版本约束；不依赖开发机全局安装。启动外部编码器等工具需校验返回码、真实输出和必要的内容解码；无关窗口不弹出。

临时文件、数据库连接、线程和锁要有明确生命周期。读取产物和导出文件不覆盖既有文件，避免并发调用共享固定临时文件名。过期的预览原型、诊断残留只在确认无引用后清理，不删除平台必需资源或用户文件。
