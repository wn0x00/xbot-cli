# 测试与验收

## 分层验证

| 层次 | 能证明什么 | 不能证明什么 |
| --- | --- | --- |
| 合同/静态检查 | 源码语法、声明、参数/模板匹配 | 实际业务可用 |
| 离线单元测试 | 分支、校验、分页、异常、格式、批次部分失败 | 目标客户端控件和提交成功 |
| 真实路径检查 | 能打开界面、找到输入和提交入口 | 未提交的动作成功 |
| 真实业务验收 | 指定账户和对象上动作执行且结果可确认 | 所有客户端和所有数据边界均支持 |

用验收证据表记录指令、用例、输入摘要、允许副作用、执行标识、输出、业务证据和结论。运行日志不应保存敏感完整正文。未执行路径必须明确标记，不能用一个总“通过”覆盖。

## 必要用例按风险选择

- 默认输入、必填缺失、空值、类型错误、固定选项和变量值。
- 条件参数互斥、单端时间范围、边界包含、数量覆盖规则。
- 同名对象、过期记录、跨账户记录、列表重排、跨页重复键和同时间记录。
- 超过一页或文案宣称上限的数据，单分片错误及不完整结果。
- 多项批次全部预校验、首项失败、中间失败、结果未知、不会自动整批重放。
- 空列表与无匹配正常返回；权限/数据库/同步失败不能伪装为空。
- 文件真实类型、媒体是否可解码、不覆盖现有文件、临时资源释放。
- 最终确认按钮确实点击，业务结果有独立证据。

不要让无关的测试写操作加入验收；使用用户授权的对象和范围。用户限制只检测路径的模块，测试不可提交，正式指令仍应保留其真实执行语义。

## 调试“最后一步未执行”

查实际执行行和目标对象，区分未定位、目标被遮挡、点偏、按钮只是打开子菜单、点击接口无效、提交失败以及结果观测失败。采集有界当前状态，不假设“无异常”就算完成。

点击后只有界面关闭时，要确认业务是否变化；数据库/页面可能有同步延迟，可有限等待原动作的证据。若证据暂不可得，标记结果未知，不再点击一次。

## CLI 运行状态

`flow check` 只做静态检查。`flow verify` 真实运行；要读业务输出和运行终态，不只看命令退出码。超时或 unknown 时保留 run_id，继续等待/查询同一运行，不能立刻新起一份任务。

区分 CLI 响应成功、任务终态成功、输出契约满足、业务证据充分。客户端重启或连接断开时先判断原任务是否可能产生动作，再恢复。

交付前让测试流程恢复无动作默认阶段，确认没有残留运行或后台辅助进程；需要常驻开发服务器等用户明确要求的服务除外。测试入口与业务指令启用状态分开核验。

## 启用状态持久化

先按[旧入口策略](contract-ui.md#旧入口的三种策略)区分弃用兼容、仅隐藏兼容与完全注销；按[元数据与交付](metadata-delivery.md)维护，不把未列入新推荐名单的兼容入口自动禁用，也不拿编辑页签数量代替指令数量。

至少覆盖：正常业务入口、保留注册的弃用入口、禁用内部模块、获授权的完全注销、设计器未关闭时禁止直接写配置、缺失/重复/歧义原型停止写入、未知字段保留和并发修改检测。仅隐藏兼容还必须验证当前版本独立展示能力；不支持时维持弃用兼容，不执行注销路径。

使用[统一只读检查入口](metadata-checker.md)，对四层精确集合、参数名称/方向/类型、可识别默认值、Python/XML签名、分组和修改前保护快照采用相同口径。正常及弃用兼容入口的可见集合与注册集合一致；仅隐藏兼容的预期集合必须分别列出，不能为满足“四层一致”删掉必要注册。脚本不会修复待测文件，也不能证明依赖可导入、运行正确、隐藏受支持或授权有效。

按风险在授权范围内验证原配置的旧消费者、正常输出、默认输入及异常行为；静态注册存在、内部导入成功或一条模拟调用都不等于旧外部调用兼容。注销前记录引用清单和迁移/退役证据；未运行的旧消费者标为未验证。

持久化验收必须独立记录关闭后的 `studio.opened=false`、正常打开后的 `true`、真实保存及完整重开后的再次保存，并以稳定快照只读比较四层及保护文件。不把 `app open --force` 回执、脚本的阶段标签或相同哈希单独当成真的关闭重开；不同阶段的人工证据按[统一报告模板](../assets/acceptance-report.md)填写。无脏变更保存未必重建注册，需按当前版本有效方式触发并核验。

当前不执行内存热更新验收，也不要求定位活对象、修改属性或执行通知。相关失败观察只保存在[历史证据](version-evidence.md)，不是可执行验收项。特定版本 reload 后保存漂移时，报告限制并用完整关闭重开路径，不改工作区页签掩盖故障。

未获发布授权时停在本地验收，明确发布后可见性尚未验证；获得授权后还要核对发布版本及使用方指令中心，不能只凭开发应用 JSON 判断发布成功。
