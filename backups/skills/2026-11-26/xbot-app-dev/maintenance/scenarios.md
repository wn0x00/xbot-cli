# 典型维护场景

- **初始页面找不到按钮**：先读调用链推导按钮出现条件；未进入正确状态，不改 XPath。见 [前置条件](element-preconditions.md)。
- **本机运行成功，用户报错**：对照实际版本、输入、账号、对象及环境；本机未复现不否定用户记录。见 [环境映射](environment-and-paths.md)。
- **参数改了但运行仍用旧值**：读 main 到 test()/业务函数的数据流，核对是否被固定值覆盖；临时调整后回读消费路径，结束恢复。见 [临时变更](temporary-values.md)。
- **点击返回成功但页面没变**：核对方法、目标子控件与业务后置；先重新观察，不自动点击第二次。Windows 见 [模块](../modules/win.md)。
- **运行超时**：只续查同一 run_id/task_id，结果未知不改源码、不跨通道重启。
- **注册/眼睛保存后漂移**：只对指令集使用 [元数据流程](../../xbot-development-standards/references/metadata-delivery.md)；普通应用不套四层公开集合。
- **未动态复现但源码有确定缺陷**：授权修复内可基于精确静态证据修改并测试，报告原问题未动态复现；不宣称现场问题已解决。
